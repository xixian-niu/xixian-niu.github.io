# Xixian Niu — job market website

Upload everything in this folder to a GitHub repository named `<your-username>.github.io`
(Public), then open https://<your-username>.github.io after 1–2 minutes.

- Photo: add `photo.jpg` here, then in index.html replace
  `<div class="avatar" aria-hidden="true">XN</div>` with
  `<img class="avatar" src="photo.jpg" alt="Xixian Niu">`
- New CV or paper version: overwrite `CV_Xixian_Niu.pdf` / `JMP_Xixian_Niu.pdf` with the same file name.
